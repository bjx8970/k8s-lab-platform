# Identity / Authorization / Security Contract v1

状态：目标契约，尚未实现。相关：[架构](architecture.md)、[模板](template-resource-contract.md)、[插件](plugin-contract.md)、[执行](execution-persistence-contract.md)。

## 1. 角色与账户

角色固定 admin、teacher、student，使用明确策略，不把“admin > teacher > student”当作自动继承所有能力的实现。

| 主体 | 账号级权限 |
| --- | --- |
| 管理员 | 管理账号、角色、状态、教师配额及平台配置 |
| 教师 | 创建 student；仅在仍为唯一管理时编辑其允许字段、重置密码、启用/禁用和删除 |
| 学生 | 查看和修改本人允许字段，修改本人密码；不修改角色、创建者或管理标记 |

created_by 是历史创建者，不应因共享化清空或改写。exclusive_management 是布尔标记：管理员创建的账号为 false；教师创建 student 为 true。非 student 不使用教师唯一管理权限。

### 1.1 永久降级规则

- 加入创建教师自己的课程：保持 true。
- 成功加入其他教师所属课程：从 true 改为 false。
- 管理员代其他教师加课也触发降级，判断依据是课程所属教师而不是请求操作者。
- 已为 false 继续保持 false；以后退出其他教师全部课程不自动恢复，v1 不提供教师自行恢复入口。
- 加课失败或事务回滚不改变标记。
- false 时创建教师失去编辑、重置、禁用和删除权限；仍可管理学生在自己课程内的成员关系和分配。
- 教师编辑接口不能接收角色、created_by、exclusive_management 等权限来源字段。

账号级授权：actor 是管理员，或 actor 是 teacher 且目标是 student、created_by=actor.id、exclusive_management=true。学生本人允许操作使用独立自服务规则。

### 1.2 并发与删除

跨教师加课、教师编辑/重置/禁用/删除都锁定同一学生账号行，并在事务内重查授权。不得先在页面或事务外读取标记，再按旧值写入。

删除平台学生账号不自动销毁实验环境，也不级联抹掉 Job、Operation 或审计。建议用户删除采用停用/保留身份的墓碑语义以维持引用；最终物理清除策略需在 DDL 与数据保留规范中显式定义，不能无意 CASCADE。教师只可删除仍属唯一管理的学生；管理员身份删除不绕过故障事实保留要求。

教师被删除或其课程所有者变更不能让原 student 唯一管理权限落到无效主体；v1 不自动转移课程，相关引用未处理时阻止物理删除。

## 2. 课程与分组

学生账号是平台级身份，可加入不同教师的课程；创建教师的账号级权利不授予对学生其他课程环境的访问。

建议 course_members 保存 course_id、student_id、可空 group_id、added_by、joined_at；UNIQUE(course_id, student_id)。group 与 course 通过组合外键校验，确保组确属该课程。

- 同一课程学生最多一个组，也可只加课未分组。
- 转组修改现有成员记录，不插入第二条同课关系。
- 移出组只是将 group_id 置空，不等于退课。
- 退课同时取消该课程组成员资格；与课程相关的直接分配不再产生有效访问。
- 小组删除不自动删除环境；组分配失效，课程成员可保留为未分组。
- 教师只能管理自己的课程、小组、成员和环境，管理员管理全部。
- 存在环境、未完成清理或执行事实的课程不得通过普通删除接口直接级联销毁；先明确处理关联。

## 3. 环境归属与分配

环境显式保存 owner_teacher_id、course_id、created_by，区分负责人和触发者。管理员代教师创建 Job 不获得环境所有权，也不让后续教师沿用管理员执行权限。

environment_assignments 包含 environment_id、course_id、group_id 或 student_id、assigned_by、状态/时间。group_id 和 student_id 恰有一个，目标必须属于环境同一课程；学生目标必须已为课程成员。支持多个组和/或多个学生分配，同一目标去重。

学生有效授权：账号有效、是该课程当前成员，并且有有效直接分配，或其当前组有有效分配。单一授权路径删除不代表其他路径失效。

- 退课、转组、撤销分配、账号禁用等后实时重算，不只靠登录时缓存。
- 移出一个组但仍有直接或其他有效路径时，不错误撤销访问或轮换凭据。
- 学生对资源的权限来自所属环境，不能通过猜 resource_id、job_id 或 session_id 越权。
- 模板角色列表只是进一步限制，不提升学生为环境创建者、删除者或分配者。
- 学生可查看授权状态、凭据，执行模板允许的启停重启等动作和 WebSSH；不能删除环境。
- 教师可管理自己环境，查看并接管其学生终端；管理员全部。

请求授权、入队事务及执行/恢复边界都要核对实时 actor 和环境归属。worker 不把过期用户快照当长期授权。已派发调用无法因撤权立刻回滚，需停止后继步骤、记录取消/阻断并处理现场；凭据和目标不因重新授权自动替换。

## 4. 模板是业务执行入口

教师/学生可提交环境/资源动作 key 和该动作允许的参数，不能提交任意 plugin_key、底层 action、目标引用、命令正文或角色。后端从不可变模板版本、资源 data 和固定创建结果解析。

管理员可发布包含任意已声明插件动作和 SSH 命令的模板，核心不做危险命令内容审批。平台仍需验证 Schema、引用、参数、授权和秘密边界。用户字符串进入管理员 Shell 命令时必须遵守模板与插件的参数化/转义约定，不可通过参数改变模板授权语义。

插件支持、模板许可、业务授权三者都满足才允许调用；这不是平台自建供应商能力白名单。前端显隐不是安全边界。

## 5. 凭据与环境访问

明确三种身份：

| 身份 | 用途 | 可向学生展示 |
| --- | --- | --- |
| 平台学生账号 | 平台登录与课程授权 | 仅本人允许信息，不涉及 SSH 管理凭据 |
| 管理连接账户 | 插件探测、执行管理命令、配置主机 | 不可 |
| 环境使用账户 | 学生实际进入实验系统 | 仅按有效环境授权和凭据就绪策略展示 |

- 普通配置、plugin Storage、模板参数、PreparedCall、Job payload、日志和审计不存明文秘密，只存用途受限的 SecretRef/版本引用。
- 密文与加密密钥分离，密钥从受控部署环境提供，不生成仓库默认值；密钥丢失不能用新密钥冒充恢复。
- SecretHandle 仅授予当前调用所需版本，不提供全库列举或跨环境任意读取。
- 原始插件输出若可能含密码，必须通过单独凭据接口保存，再返回引用；stdout/stderr 不能作为秘密存储。
- 环境密码由平台随机生成时，必须由模板步骤在远端实际设置并确认，再标为 ready 并展示。插件没有账户/密码设置能力时不得声称随机密码可用。
- 平台不实现学生与环境 OS 用户一一绑定，允许同一环境使用共享账户；不能据此宣称远端用户级隔离。
- v1 不实现私有 CA、证书签发或 AuthorizedPrincipalsCommand。

授权查看范围：管理员可查看全部可用环境凭据；教师查看自己环境；学生查看自己当前获权环境。管理连接凭据不因同一教师拥有环境而展示给学生。凭据查看独立鉴权、审计、禁止缓存，不包含在普通列表、事件或 Job 结果中。

## 6. WebSSH、旁观与接管

环境或资源必须由模板显式声明 access 会话入口，使用已确认目标和环境凭据。不能自动用 SSH 插件管理账户作为学生入口。

会话记录包含平台 actor、环境、可选资源、模板动作、插件实例、固定连接/凭据版本、建立 Operation、状态、控制者及结束原因。运行时连接句柄不持久化冒充可恢复。

- 所有输入、输出、resize、回放、重连、旁观、接管都重新检查有效权限。
- 同一会话至多一个输入控制者，旁观只读；接管使原 owner 暂停输入，释放后按授权恢复。
- 教师只能对自己有权管理的环境旁观/接管，不能因为创建了某学生账号就查看其其他教师课程终端。
- 接管、释放、凭据查看和会话关闭有可关联审计。默认不审计完整终端输入，不承诺记录所有远端命令。
- 输出/回放缓冲有界，传输帧受限，慢客户端不能导致无限内存。
- 重启后无恢复协议的会话标为 disconnected，不能自动恢复 PTY 或重放已发送输入。

## 7. 平台撤权与远端撤权

允许学生查看密码并用外部客户端直连 SSH，因此平台不能撤回其已经知道的密码，也不能保证换密码自动终止旧 SSH 会话。

失去所有有效授权路径时：

1. 立即拒绝新的凭据查看、资源动作和 WebSSH 建连。
2. 关闭对应平台会话，停止转发输入和输出。
3. 对该学生可能掌握的仍有效环境凭据，发起模板/插件支持的轮换或失效流程。
4. 如有受控远端会话终止能力，按策略执行，避免误杀仍有权用户或管理连接。
5. 未确认远端处置时显示 revocation_pending/revocation_failed，不报告完全撤权成功。

共享凭据轮换可能影响其他仍有权学生，需更新其可见版本和连接状态。轮换、终止失败不撤销平台侧即时拒绝，但必须保留未完成事实。没有能力时明确标为不支持/未完成，不伪装已轮换。

Job/冲突保护只约束平台调度的调用，不能阻止外部 SSH 或交互终端命令并发修改同一系统。平台会话日志也无法覆盖外部直连行为。

## 8. HTTP、实时接口与审计

- Session Cookie 使用 HttpOnly、明确 SameSite；生产 HTTPS 下 Secure。
- HTTP 修改接口执行 CSRF 与精确 Origin 校验，不允许通配符凭据跨域。
- 实时连接校验登录、Origin 与每次动作/输出授权，不信任长期角色房间缓存。
- 长操作返回 202、job_id 和状态位置；不存在面向普通用户的任意插件调用 API。
- 错误统一 code、message、request_id 和安全 details，不返回原始供应商异常、密码、私钥或密文。
- 审计持久化 actor、动作、模板版本、环境/资源、Job/Operation、结果和时间；敏感数据先脱敏。
- 审计追加保存，不能被账号/课程/资源删除级联抹掉。脱敏降低误泄露风险，不承诺能从任意终端文本自动识别所有秘密。

## 9. 最低验收

1. 教师创建学生为唯一管理，管理员创建为共享。
2. 管理员或其他教师成功加入其他教师课程后永久降级；失败回滚不降级。
3. 降级后创建教师四类账号管理操作全部拒绝，退课不恢复。
4. 并发加课与编辑/重置/禁用/删除串行授权，不依赖事务外旧标记。
5. 同学生跨教师课程可共存，同课程只能一个组或未分组，外课组组合外键失败。
6. 直接与组授权取并集，删除一条路径不错误撤权；退课后本课直接分配也不再授权。
7. 教师管理学生账号不授予其他教师环境权限；管理员代建 Job 不影响所有权。
8. 任意替换插件、动作或目标参数不能绕过模板后端校验。
9. 学生无法查看管理凭据；环境密码未在远端确认生效前不可展示。
10. 撤权关闭平台终端和输出，同时准确展示未完成的远端撤权。
11. 教师旁观/接管重新鉴权且审计，旁观不可输入，控制权唯一。
12. 不因删除平台学生或课程而自动销毁外部环境或删除执行证据。
