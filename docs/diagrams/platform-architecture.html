通用实验平台对象驱动控制面

API 只提交对象；Scheduler、Controller 与 Executor 围绕 PostgreSQL 中的持久状态独立工作。

对象驱动路径

  • Environment.spec → Placement → PlanRevision → Operation
  • Operation → Resource Framework → 外部平台 → Resource.status
  • Controller 根据真实状态更新 Environment conditions

可靠性边界

  • 数据库状态保证正确性，通知只降低延迟
  • 重复 reconcile 复用同一确定性 Operation
  • Unknown 时不重发、不释放 Allocation、不移除 finalizer
